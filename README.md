# autoclicker — 悬浮窗鼠标自动点击器

一个基于 Windows Win32 API + Tkinter 的**鼠标自动点击器**，带深色悬浮窗界面。
纯 Python 标准库实现，**零第三方依赖**，即下即用。

## 功能特性

- **两种注入方式**
  - 物理点击：真实移动鼠标并触发系统级点击
  - 后台注入：通过 `PostMessage` 向目标窗口直接发送鼠标消息，不占用物理鼠标
- **多种点击配置**：单击 / 长按；左键 / 右键 / 中键；次数 / 按住时长 / 间隔均可调
- **三种点击位置**：窗口内随机、窗口中心、鼠标拾取（基于窗口坐标，随窗口移动）
- **深色悬浮窗 UI**：可拖动、可最小化、常驻桌面
- **全局热键**：`Ctrl+Alt+Home` 开始点击，`Ctrl+Alt+End` 紧急终止
- **安全停止**：目标窗口关闭 / 尺寸异常时自动跳过或停止

## 环境要求

| 项目 | 要求 |
| ---- | ---- |
| 系统 | Windows（依赖 Win32 API，不支持 Linux/macOS） |
| Python | 3.8+（需自带 Tkinter，官方安装包默认包含） |

## 快速开始

```bash
python dianji.py
```

操作步骤：

1. 打开目标窗口，点击悬浮窗中的 **刷新** 并选择目标窗口
2. 选择注入方式（物理点击 / 后台注入）与鼠标按键
3. 设置点击次数、按住时长、点击间隔
4. 选择点击位置（窗口内随机 / 中心 / 鼠标拾取）
5. 点击 **开始**，或直接按全局热键 `Ctrl+Alt+Home`
6. 随时按 `Ctrl+Alt+End` 紧急终止，或点击悬浮窗 **停止**

> 鼠标拾取模式：点击 **拾取位置** 后，将鼠标移到目标窗口内任意位置，等待约 1 秒自动完成拾取。

## 常见问题

- **后台注入无效果**：部分程序（如许多游戏、DirectX 应用）不响应 `WM_*` 消息，
  请切换到「物理点击」模式；后台注入仅对标准 Win32 窗口有效。
- **需要管理员权限**：若目标进程以管理员身份运行，请以管理员身份运行本脚本。
